06 / CONTRIBUTION SNAKE

<div align="center">
<img width="100%" src="https://raw.githubusercontent.com/ankitmx-byte/ankitmx-byte/output/github-snake-dark.svg" alt="Animated GitHub contribution snake"/>
</div>

To enable the snake, create .github/workflows/snake.yml in this repository:

name: Generate Contribution Snake
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main
permissions:
  contents: write
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ankitmx-byte
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
      - name: Publish SVG
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

Save the workflow, open the repository’s Actions tab, and run it manually. The output branch must exist and contain the generated SVG before the image will display.
